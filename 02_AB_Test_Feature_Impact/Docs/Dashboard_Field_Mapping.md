# Dashboard Field Mapping (Visuals ↔ Data)

Use this file to explain *exactly* how the dashboard visuals are powered by the CSV tables.

## Table: `ab_sessions`
**Primary fields:** session_id, session_date, variant, device, source, converted, engagement_score, bounce, revenue
**KPIs/Visuals supported:**
- Conversion rate by variant
- Engagement by variant/device
- Bounce rate by variant
- Revenue lift by variant/source
